## Codebase Patterns
- Write slice with only idempotency: query = event type scoped by its id tag; execute returns {:ok, []} when already folded.
- Slice folder/module naming: lib/library/slices/<snake_slice>/ (e.g. add_book), command module = slice name (AddBook.AddBook).
- No test-analyzer skill ships in this kit (step 14 of the loop prompt): skip and note it.
- AGENTS.md is generated: add learnings with `npx @eventmodelers/cli learn`, never by hand.
- An automation whose queue slice isn't built: build against the queue's assumed Context, calling it dynamically (module held in the processor state).
