# Screen: Return a book

Slice `Return book` · node `c150cd06-3376-4038-ae81-169462a5c1e6` · written by the loop on 2026-11-16.

Mockup: designed on the board — `get_node` with the id above (one page: a "Book" select
showing "Title — Author" with the help text "Only books that are on loan.", a "Return book"
button and a "Cancel" button).

## How it's entered

The book picker is filled from the `Catalogue` slice (the screen's `books`, `authors` and
`available` fields map to `Catalogue.title` / `Catalogue.author` / `Catalogue.available`):

```elixir
Library.Slices.Catalogue.Context.catalogue() :: [
  %{book_id: String.t(), title: String.t(), author: String.t(), available: boolean()}
]
```

The form is built from the command (`returned_at` is generated by the Context; pass it as
the derived second argument only if the form needs it to validate):

```elixir
to_form(Library.Slices.ReturnBook.ReturnBook.changeset(params))
```

## What it returns

From the catalogue, one option per book:

| field | type | | what it is |
|---|---|---|---|
| `books` | `String` (list) | | mapped to `Catalogue.title` |
| `authors` | `String` (list) | | mapped to `Catalogue.author` |
| `available` | `Boolean` (list) | | mapped to `Catalogue.available`; the mockup lists only books on loan, i.e. `available: false` |

The form's fields:

| field | type | | what it is |
|---|---|---|---|
| `bookId` | `UUID` | required | the selected book, mapped to `ReturnBook.bookId` |

## What it sends back

```elixir
Library.Slices.ReturnBook.Context.return_book(%{"book_id" => book_id})
# {:ok, loan_id}                # the loan that was closed
# {:error, %Ecto.Changeset{}}   # book_id missing/blank (validation: :required)
# {:error, :book_not_lent}      # board: "A book that isn't lent can't be returned",
#                               #        "A book already returned can't be returned twice"
# {:error, :store_unavailable}  # the event store isn't up
```

Domain error atom to translate: **`:book_not_lent`**. Plus `:store_unavailable` (infrastructure).

## States to render

- No book on loan: nothing to return.
- Form with a book selected.
- Field error once touched or submitted (`used_input?/1`).
- Submitted: `{:ok, loan_id}` — the catalogue now shows the book as available; where to go next isn't on the board.
- `:book_not_lent` (e.g. someone else returned it meanwhile) or `:store_unavailable`: nothing was recorded.

## What the board says about this screen

The screen node has no `description`.

## What the domain does NOT give you

- No member on the form: the domain finds the open loan (and its member) from the book alone.
- No return date input: `returnedAt` is set by the Context at the moment of the call.
- No late-return flag or fine: the domain records the return, nothing about whether it was overdue.
- The catalogue gives no member or due date per book; the picker can only show title and author.
- "Cancel" has no domain counterpart; it's navigation only.
